# Ez 桌宠使用说明

桌宠是 Ez 自己的全屏层，**不是皮肤组件，也不是 Ez 布局编辑器组件**。不用拖出来摆放。换皮、重置 HUD、隐藏游戏内 HUD 都不会丢掉它。位置、开关、包名写在 Ez 配置里。

---

## 1. 打开与放置

设置路径：**Ez 游玩设置 → 桌宠**

| 项 | 作用 |
| --- | --- |
| 启用桌宠 | 总开关。关掉后任何场景都不显示 |
| 主菜单显示 | 主菜单是否允许出现 |
| 选歌界面显示 | 选歌是否允许出现 |
| 游戏中显示 | 游玩是否允许出现（仍可被 pet.json 的 hide/show 临时覆盖） |
| 结算显示 | 结算界面是否允许出现（可配合 `resultsRank` + motion） |
| 桌宠包 | 扫描 `EzResources/Pets/` 下带 `pet.json` 的文件夹 |
| 桌宠缩放 | 立绘大小 |

**位置**：鼠标放在立绘上，按住 **Left Alt + 左键拖动**，松手写入配置。不要去布局编辑器里找它。

**何时显示**：总开关 + 当前场景勾选（含结算），再减去 `pet.json` 里尚未被 `show` 抵消的 `hide`。离开游玩后，局内 hide 会清掉。

完整可复制配置：[`docs/Pets/pet.json`](Pets/pet.json)（进图隐藏，combo 200 显示并播动画，combo 500 再隐藏）。

**游玩点击**：普通点击会穿透立绘，不抢准星。悬停仍可播动画。Left Alt 拖动始终可用。

## 2. 包目录（按动作分文件夹）

游戏数据目录下：

```
EzResources/Pets/
  Default/                 ← 自带包（无帧时显示固定提示文案）
    pet.json
  Guga/                    ← 你的包名，设置里选这个
    pet.json
    idle/
      任意名字_000.png
      任意名字_001.png
    hover/
      xxx_000.png
    poke/
      poke_000.png
    starEasy/              ← 也可以写成 star_easy
    starHard/
    enter/
    gameplay/              ← 游玩中循环（不是 idlePlay）
    combo50/
    combo200/
    combo300/
    miss/
    idlePlay/              ← 非游玩闲置自娱（也可以写成 idle_play）
    idleYawn/
    idleSleep/
    grabbed/               ← 拖动时（可选）
  Doro/
    pet.json
    idle/
      ...
```

规则：

1. **一个动作一个文件夹**。文件夹名匹配 clip 名（见第 4 节），大小写不敏感。
2. `starEasy` 也可以用 `star_easy`，`idlePlay` 也可以用 `idle_play`。
3. 文件夹里的文件名随意，**只要有 `_数字` 后缀**（紧挨扩展名）就会被当成帧。统一用三位：`_000` `_001` … `_095`。`_00` 也能认，但不建议混用。
4. 按数字从小到大播放，最多 120 帧。同一序号多张时取文件名排序更靠前的一张。
5. 支持 `.png` / `.jpg` / `.jpeg`。建议透明 PNG；若 AI 出图是纯黑底、未抠图，可在 `pet.json` 设 `"blendMode": "blackKey"`（见第 3 节）。
6. 缺某个动作文件夹，或文件夹里没有任何 `_XXX` 文件：这个动作不触发，其它动作照常。

合法帧名示例（都在 `idle/` 里）：

```
idle_000.png
guga_000.png
frame_001.png
小咕嘎待机_000.png
a_0.png
a_1.png
a_12.png
```

不认（没有 `_数字` 后缀）：

```
idle.png
idle-000.png
000.png
idle000.png
```

建议从 `_000` 连续编号，中间缺号也可以，会按现有序号排序后播放。

## 3. pet.json

每个包根目录必须有 `pet.json`。可以先复制 `Default/pet.json`。

`clips` 的 key 就是动作名，也是默认文件夹名：

```json
"idle": { "fps": 12, "loop": true },
"poke": { "fps": 15, "loop": false }
```

可选字段：

| 字段 | 含义 |
| --- | --- |
| `fps` | 播放帧率 |
| `loop` | 是否循环。一次性动画播完会按 `states` 里的 `next` 回去（一般回 `idle`） |
| `folder` | 自定义文件夹名。不写就用 clip 名 |
| `blendMode` | 可选，覆盖包级混合模式（见下） |

包根可选 `"blendMode"`，控制帧如何叠到画面上（不用抠图也能去纯黑底）：

| 值 | 效果 |
| --- | --- |
| `normal`（默认） | 普通 Alpha 混合，适合透明 PNG |
| `additive` | 加法混合（发光类素材） |
| `blackKey` | 纯黑背景消底：黑色像素不写入，彩色像素叠加；AI 出黑底图可直接用 |

示例（整包黑底 AI 图）：

```json
{
  "defaultState": "idle",
  "blendMode": "blackKey",
  "clips": {
    "idle": { "fps": 24, "loop": true }
  }
}
```

某个 clip 需要不同混合时可单独写 `"blendMode"`。

`states`：动作播哪个 clip、播完去哪。`rules`：什么事件做什么。`action` 缺省为 `play`。

| `action` | 效果 |
| --- | --- |
| `play`（默认） | 跳到 `goto` 对应 state，播动画。缺 clip 则不触发 |
| `show` | 显示桌宠；若写了 `goto` 同时播动画 |
| `hide` | 隐藏桌宠，直到之后的 `show`，或离开游玩 |

完整默认配置（含进图隐藏 / combo 200 显示 / combo 500 隐藏）见 [`docs/Pets/pet.json`](Pets/pet.json)，复制到 `EzResources/Pets/<包名>/pet.json` 即可。

内置 Default 包仍是「进图播 enter → gameplay 循环、combo 50/300 播完回 gameplay」，没有 hide。要改成文档这份行为，用上面的文件覆盖。

默认规则（Default 包）：

| 事件 | 动作 | 说明 |
| --- | --- | --- |
| 鼠标悬停立绘 | `play` → `hover` | 离开且当前是 hover 则回 idle |
| 点击立绘（非游玩） | `play` → `poke` | 可打断 |
| 拖动立绘 | `play` → `grabbed` | 松手回 idle；缺 grabbed 帧仍可拖动 |
| 选歌星数 `[0, 2)` | `starEasy` | 仅在有硬件操作时触发；AFK 轮播不切 |
| 选歌星数 `[4.5, 99)` | `starHard` | 同上 |
| 进入 Player（跳过 PlayerLoader） | `play` → `enter` → `gameplay` | 每局进图一次；缺 gameplay 帧则回 idle |
| 离开 Player | 回 `idle` | |
| combo 到 50 / 300 | `play` → `combo50` / `combo300` → `gameplay` | 本局每档一次 |
| miss（断连） | `play` → `miss` → `gameplay` | 每次；json 里可加 `"streak": 3` |
| 硬件闲置 300 / 600 / 900 秒 | `play` → idlePlay / idleYawn / idleSleep | **仅非游玩**；键鼠等输入会清零并退出这些状态 |
| 进入结算 | `resultsRank` + 可选 `motion` | 见第 6 节 |

文档模板额外示范：

```json
{ "when": "gameplayEnter", "action": "hide" },
{ "when": "combo", "at": 200, "action": "show", "goto": "combo200", "interrupt": true },
{ "when": "combo", "at": 500, "action": "hide" }
```

**闲置判定**：无鼠标 / 键盘 / 触控板 / 已映射手柄键等硬件输入才算闲置。游戏内轮播、自动换图不算交互。游玩中不累计 idlePlay 档。

## 4. 动作文件夹一览

| 文件夹（二选一） | 循环 | 典型用途 |
| --- | --- | --- |
| `idle` | 是 | 非游玩默认待机 |
| `hover` | 是 | 鼠标停在立绘上 |
| `poke` | 否 | 点一下 |
| `starEasy` / `star_easy` | 否 | 简单谱 |
| `starHard` / `star_hard` | 否 | 难谱 |
| `enter` | 否 | 进游玩一次性反应 |
| `gameplay` | 是 | **游玩中**默认循环（看你打歌；不是 idlePlay） |
| `combo50` | 否 | 小连击档 |
| `combo200` | 否 | 文档模板：显示并播动画 |
| `combo300` | 否 | 大连击档 |
| `miss` | 否 | 失误 |
| `idlePlay` / `idle_play` | 否 | **非游玩**闲置自娱（硬件无输入一段时间） |
| `idleYawn` / `idle_yawn` | 否 | 更久闲置 |
| `idleSleep` / `idle_sleep` | 是 | 睡着（有输入才醒回 idle） |
| `grabbed` | 是 | 拖动时（揪住）；缺帧则拖动仍可移动但不切动画 |

生成动画时：先画 `idle`，把第一帧当参考，再按文件夹丢其它动作。

## 5. 制作规范（体积与衔接）

1. **禁止把走位烤进序列帧**：角色画布尽量紧包围；屏幕走动 / 走到结算旁用 `motions` 移动 `petBox`，不要出超大位移帧。
2. **单 clip 建议**：长边 ≤512、帧数 ≤120；idle 可用更高 fps，一次性反应可更短。
3. **视频切帧**：固定画幅与角色比例；循环动作注意首尾相接；黑底可用 `"blendMode": "blackKey"`。
4. **运行时**：clip 贴图按需加载，切走后会卸载（保留当前与 default idle），减轻多动作包常驻内存。
5. **社区 / 自定义包 = PNG 序列帧**（视频切帧同此格式）。

Live2D：分支 `ez-pet-live2d-builtin` — 扫描目录共用，**仅官方白名单包名 + 模型入口 SHA-256** 才 `Live2DAuthorized`；自制 moc3 默认不授权。Cubism Native 尚未链接时显示占位层，状态机 / motion 仍可用。

官方预设目录：

```
EzResources/Pets/<官方包名>/
  pet.json          # "renderer": "live2d"
  live2d/
    xxx.model3.json
    …
```

向 `EzPetLive2DAccess.PresetHashes` 登记哈希后才会授权。

## 6. 舞台 motion（pet.json）

在包根增加 `motions`，规则里用 `"motion": "id"` 触发（与 clip 正交）：

```json
"motions": {
  "wander": { "mode": "wander", "speed": 0.05, "bounds": [0.12, 0.22, 0.88, 0.82] },
  "toRank": { "mode": "moveTo", "anchor": "results.rank", "durationMs": 450, "easing": "OutQuad" }
},
"rules": [
  { "when": "idle", "afterSeconds": 300, "goto": "idlePlay", "motion": "wander" },
  { "when": "drag", "goto": "grabbed", "interrupt": true },
  { "when": "resultsRank", "rank": "S", "goto": "proud", "motion": "toRank", "interrupt": true }
]
```

| `mode` | 含义 |
| --- | --- |
| `wander` | 在 `bounds` 归一化矩形内闲逛 |
| `moveTo` | 在 `durationMs` 内缓动到 `target` `[x,y]` 或 `anchor` |
| `teleportTo` | 立刻跳到目标 |

`when: resultsRank`：进入结算时触发；可选 `"rank": "S"`（亦支持 `SH` / `X` 等 `ScoreRank` 名）；不写 `rank` 则任意评级。当前 `results.rank` 锚点为结算屏近似位置（后续可改为精确查询 HUD）。

## 7. 做自己的包（PNG）

1. 在 `EzResources/Pets/` 新建文件夹，名字就是设置里的包名（如 `Guga`、`Doro`）。
2. 放入 `pet.json`（可复制 [`docs/Pets/pet.json`](Pets/pet.json) 或游戏目录里的 `Default/pet.json`）。
3. 按第 4 节建动作文件夹，把序列帧丢进去（文件名用 `_000` `_001` …）。
4. 游戏设置里选这个包。已打开的游戏改文件后需重进或切一下包名才会重载。

生成提示词（角色定妆 + 分镜）在：

- `osu.Game/EzOsuGame/Pets/prompts/咕嘎-动画帧生成.md`（终末地女管理员企鹅 Q 版）
- `osu.Game/EzOsuGame/Pets/prompts/Doro-动画帧生成.md`（NIKKE 桃乐丝 Q 版）

输出请按**动作分文件夹**，不要全部平铺在包根目录。

## 8. 常见问题

**只有提示文案没有立绘**  
Default 包或所选包没有动作帧时，会显示「当前没有可用的宠物包 / No pet pack available」。把 PNG 放进对应文件夹即可。

**某个动作不播**  
检查文件夹名是否匹配 clip、里面是否至少有一张 `*_000.png` 这类带 `_数字` 的文件、该 clip 是否在 `pet.json` 的 `clips` / `states` 里。

**启用了但完全看不到**  
确认「启用桌宠」与当前场景勾选。它不会出现在皮肤/布局编辑器组件列表里。默认在屏幕右下；用 Left Alt 拖动。改完帧文件后切一下包名或重启才会重载。

**点了没反应**  
游玩时普通点击故意穿透。到选歌界面再点，或只看悬停。

**挡住按键 / 准星**  
游玩时未按 Left Alt，立绘不接收普通点击。若仍挡到暂停按钮，用 Alt 拖开即可。
